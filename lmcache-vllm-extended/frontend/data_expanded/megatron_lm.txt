Megatron-LM: Training Multi-Billion Parameter Language Models Using Model Parallelism
Authors: Mohammad Shoeybi, Mostofa Patwary, Raul Puri, Patrick LeGresley, Jared Casper, Bryan Catanzaro

Abstract
Training large language models requires vast amounts of compute and memory. Megatron-LM introduces a simple, efficient intra-layer model parallel approach that enables training models with billions of parameters across multiple GPUs.

1. Introduction
While data parallelism scales to many GPUs, it requires the entire model to fit on a single GPU. As models grow beyond the memory limits of a single accelerator (e.g., beyond 16GB or 32GB), model parallelism becomes strictly necessary.

2. Tensor Model Parallelism
Megatron-LM splits the execution of individual Transformer layers (both the Self-Attention and the Feed-Forward Network) across multiple GPUs. By partitioning the weight matrices, GPUs compute partial results and synchronize them using an All-Reduce communication primitive.

3. Implementation
The system requires minimal code changes to native PyTorch. It relies heavily on fast inter-GPU communication topologies like NVIDIA NVLink to keep the All-Reduce overhead low.

4. Results
The authors successfully trained an 8.3 billion parameter Transformer model using 512 GPUs, demonstrating near-linear scaling and pushing the boundaries of what was achievable in natural language processing at the time.
